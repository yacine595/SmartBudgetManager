# SmartBudgetManager
A project for managing Budget
README SmartBudget Manager is an Excel file that help users manage their monthly money. It allow users to record income and expenses, calculate the balance and show expenses by category. The workbook contain three sheets Dashboard, Transactions and Categories. To start, open the Excel file and go to Transactions to enter your income and expenses. Then open Dashboard to see your results. You need Microsoft Excel or a compatible program to use this file.
